# Tarih Ustaz AI

**Сайт:** https://dosalin007.github.io/tarih-tanym-ai/

Басты бетте автор жасаған үш ChatGPT боты бар. Карточканы басқанда бот ChatGPT-де жаңа қойындыда ашылады:

1. **Тарих Ұстаз · ҚМЖ / КСП** — сабақ жоспары, жұмыс парағы, мұғалімге жауап кілті.
2. **Қазақстан тарихы көмекшісі** — тақырыптарды түсіндіру, тапсырмалар мен сұрақтар.
3. **Qazaq Tarih Academy** — Қазақстан тарихы бойынша ҰБТ/ЕНТ дайындығы.

Сайт қазақша және орысша жұмыс істейді. Тіл таңдауы браузерде сақталады. Боттарды қолдану үшін келуші ChatGPT аккаунтына кіреді. Сайттың өзінде материал жасайтын редактор, КТЖ/КТП құрастыру, файл экспорттау және AI API жоқ; олар басты беттен алынып тасталды.

## Басты бет файлдары

- `index.html` — үш ботқа апаратын сілтемелер мен екі тілдегі мәтін.
- `bots.css` — бейімделетін дизайн.
- `bots.js` — тіл ауыстыру және тілді сақтау.
- `cabinet.html` — бұрынғы мекенжайдан басты бетке өту.

Репозиторийдегі бұрынғы шеберхана файлдары тарихи код ретінде сақталған, бірақ жарияланған басты бет оларды жүктемейді. Боттардың маршруты `plugin-routing.json` файлында да көрсетілген.
