# Tarih Ustaz AI — Тарих мұғалімінің цифрлық шеберханасы

**Сайт:** https://dosalin007.github.io/tarih-tanym-ai/

Тарих пәні мұғалімдеріне арналған қазақша және орысша цифрлық шеберхана. Басты бетінде музей стиліндегі тарихи безендіру, алты жеке иллюстрация, тарихи галерея, алтын және көк түсті дизайн, функционалды бөлімдер және тіркелусіз толық ашылатын шеберхана бар.

## Қорғауда көрсетуге арналған шеберхана

- **Инфографика:** тарихи фактілерден визуалды HTML-инфографика үлгісін құрастыру
- **Слайдтар:** 16:9 өлшемді төрт слайдтың HTML көрсетілімін дайындау
- **ҚМЖ / КСП:** 45 минуттық сабақ жоспарының өңделетін үлгісі
- **Жұмыс парағы:** жазбаша тапсырмалар мен жауап жолдары
- **Тест-форма:** сұрақтарды өңдеу, дұрыс жауапты таңдау, автоматты тексеру, HTML экспорт
- **HTML-ойын:** CSS 3D эффектісі бар интерактивті викторина, **index.html** жүктеу

Редакторға пән, сынып, тіл, тақырып, оқу мақсаты мен деректер енгізіледі. HTML файлдар браузерде дербес ашылады. PDF-ке экспорттау үшін браузердің басып шығару мүмкіндігін пайдалануға болады.

## AI-көмекшілер және ChatGPT

Сайттағы бұрынғы үш GPT-ботқа тікелей сілтеме пайдаланылмайды, себебі олар «GPT не найден» қатесіне әкелуі мүмкін. Оның орнына шеберханада енгізілген тақырып, пән, сынып және оқу мақсаты бойынша **ChatGPT жаңа сұранымын бір батырмамен ашатын** үш бағыт бар:

- **Тарих Ұстаз | ҚМЖ • КСП:** 45 минуттық жоспар, дескрипторлар, жұмыс парағы
- **Қазақстан тарихы мұғалімінің көмекшісі:** оқиға, себеп-салдар, хронология және дереккөздер
- **Qazaq Tarih Academy:** ҰБТ/ЕНТ үлгісіндегі тест сұрақтары

Екі батырма жұмыс істейді: «Сұранымды көшіру» және «ChatGPT-де ашу». ChatGPT жаңа бетте `?q=` параметрімен алдын ала құрастырылған сұранымды алады. Параметр ChatGPT-дің ресми интеграциялық API-і емес және болашақта өзгеруі мүмкін.

**Шектеулер:** Бұл бұрынғы Custom GPT боттарының өзі де, тікелей іске қосылған жеке плагин де емес. Плагинге көшіру ChatGPT-дегі `My GPTs → Migrate to plugin` арқылы, егер аккаунтта қолжетімді болса, жасалады. Сайт ішінде жеке AI-ботты іске қосу үшін сервер мен API кілті қажет; API құпия кілтін GitHub Pages клиенттік кодына салуға болмайды.

## Файлдар

- `index.html` — жаңа ашық басты бет
- `studio.css` — адаптивті визуалды дизайн
- `studio.js` — браузерлік редакторлар мен HTML экспорт
- `heritage-hero.svg` — басты беттегі тарихи иллюстрация
- `illustration-info.svg`, `illustration-slides.svg`, `illustration-qmj.svg`, `illustration-sheet.svg`, `illustration-form.svg`, `illustration-game.svg` — алты құралға арналған иллюстрациялар
- `museum-theme.css` — музей стиліндегі жаңартылған визуалды дизайн
- `cabinet.html` — ескі мекенжайдан ашық шеберханаға бағыттау; логин мен пароль жүйесі толық алынды

## Қазіргі мүмкіндіктердің шегі

- ҚМЖ, инфографика, слайд және жұмыс парағы — **жергілікті редакцияланатын үлгілер**, AI-дің дербес генерациясы емес.
- Ойын — нақты жұмыс істейтін HTML викторина және CSS 3D эффекті. Әзірше толыққанды WebGL 3D-сахна генераторы емес.
- Тесттерді HTML ретінде жүктеуге және жауапты сол браузерде бағалауға болады; **Google Forms бұлттық базаға нәтижелерді жинау** іске қосылмаған.
- Canva ішіне автоматты экспорт немесе бірлесіп редакциялау қосылмаған.
- Сайттағы тарихи мәліметтерді және сабақ мақсаттарын мұғалім тексеруі керек.

## Қолжетімділік

Сайтқа кіру үшін логин және пароль **қажет емес**. Барлық редакторлар басты бетте қолжетімді. `auth.js` және `config.js` ескі файлдары жойылған.

- Әр құралда және редакторда «Жасау» батырмасы. Дайын HTML материал арнайы қарау терезесінде сайттан шықпай ашылады.

- Интерактивті HTML викторинасы мен тесті браузерде жұмыс істейді.
- Фотосуреттерді көрсету үшін интернет керек болуы мүмкін; өз фотосын пайдаланғанда файл материалға енгізіледі. Фотоиллюстрация редакторы AI арқылы жаңа фотосурет генерацияламайды.
- workshop-pro.js — жасау, қарау, жергілікті сақтау және жүктеу логикасы.
