# Tarih Ustaz AI — Тарих мұғалімінің цифрлық шеберханасы

Сайт: https://dosalin007.github.io/tarih-tanym-ai/

## Ағымдағы нұсқа (2026-11-23)

Сайт тіркелусіз жұмыс істейтін **үш құралға** дейін ықшамдалды:

1. **Слайдтар** — 16:9 форматында төрт слайд, бірегей фото, тақырып, мақсат және тарихи фактілер.
2. **Инфографика** — 4:5 форматындағы иллюстрациялы тарихи деректер постері.
3. **Фотоиллюстрация** — 16:9 форматындағы иллюстрациялы тарихи постер.

Тек сайттың өзінде: пән/сынып/тақырып/мәтін/фото/түсті таңдау → **Жасау** → сайт ішіндегі үлкейтілген қарау терезесі → PNG/JPG/HTML/PDF экспорт. Слайдтар үшін PNG/JPG ағымдағы слайдты, HTML/PDF төрт слайдты экспорттайды. PDF браузердің басып шығару терезесі арқылы жасалады.

«Менің материалдарым» бөлімі соңғы 8 жұмыстың параметрлерін осы браузердегі localStorage-ға сақтайды. Қайта ашу, редакциялау және өшіру қолжетімді; басқа құрылғыларға синхрондау жоқ.

Ешқандай GPT, ChatGPT, плагин немесе сыртқы AI чатқа өтетін батырма жоқ. Контент пайдаланушы енгізген деректерден жергілікті Canvas арқылы жасалады. **Бұл автоматты AI-мазмұн немесе жаңа фотосурет генераторы емес.** Тарихи деректің дұрыстығын мұғалім тексереді.

## Негізгі файлдар

- `index.html` — негізгі интерфейс: үш құрал және материалдар кітапханасы
- `app.css` — кәсіби адаптивті дизайн
- `app.js` — Canvas редакторлары, алдын ала қарау, экспорттау, жергілікті сақтау

Бұрынғы `studio.js`, `workshop-pro.js` және олардың CSS файлдары жаңа басты бетке қосылмайды (ескі нұсқаның архивтік коды).

Фотосуреттер Wikimedia Commons-та орналасқан. Әр бөлімдегі негізгі суреттер әртүрлі:

Фотолар алдын ала қарауда және файлдарда өңделген (қиылып, түсі түзетілген) түрде пайдаланылады. Дереккөз бен лицензияға сілтемелер сайттың төменінде берілген. Суреттерді Canvas-қа жүктеу кезінде CORS немесе желі қатесі туындаса, градиенттік фонға қауіпсіз ауысады. Өз JPG/PNG/WebP суретін (2 МБ дейін) жүктеуге болады.
