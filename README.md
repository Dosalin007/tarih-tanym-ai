# Тарих Таным AI

Авторская образовательная AI-платформа для учителей и учеников.

## Основные модули
- КСП / ҚМЖ — только «Тарих Ұстаз | ҚМЖ • КСП»
- ЕНТ — только Qazaq Tarih Academy
- Помощник учителя — только «Помощник учителя истории Казахстана»
- Canva — презентации и инфографика на основе уже подготовленного содержания

## Концепция
Учитель один раз вводит тему, класс, язык и цели обучения. Платформа формирует единый Lesson Package:
КСП/ҚМЖ → рабочий лист → ключ → инфографика → Canva-презентация.

Все элементы должны быть синхронизированы по целям, заданиям, дескрипторам и терминологии.

## Языки
Русский / Қазақша

## Статус
Текущая версия — интерактивный прототип. Для реальных аккаунтов, общей базы данных и вызова AI-модулей требуется серверный слой.

## Развитие
- Google OAuth / Google Classroom
- Supabase/PostgreSQL
- реальные кабинеты учителя и ученика
- экспорт DOCX/PDF
- Excel-аналитика
- апробация среди педагогов
